# Orixeo Learning Studio Web MVP

Prototype statique du Designer Orixeo.

## Tester localement

Depuis la racine du dépôt :

```bash
python3 -m http.server 8080
```

Puis ouvrir :

```text
http://localhost:8080/apps/web/
```

## Fonctionnalités actuelles

- saisie du brief ;
- choix d’un modèle pédagogique ;
- génération d’un scénario structuré ;
- affichage des séquences et activités ;
- indication du niveau d’assistance IA ;
- export JSON.
